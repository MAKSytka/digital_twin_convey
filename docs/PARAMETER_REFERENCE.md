# Справочник параметров

Этот файл описывает принятую конфигурацию финальных демонстраций. Источником истины остаются launch-, SDF- и Python-файлы; после изменения реализации документацию необходимо обновлять синхронно.

## 4. Машинное зрение сингулятора

Классический CV-контур получает кадры камеры Gazebo и формирует:

```text
id
центр товара
габариты
yaw
confidence
оценку движения
```

Нейросеть не используется. Основной выход:

```text
/singulator/boxes
singulator_interfaces/msg/BoxObservationArray
```

Межосевой шаг 150 мм при диаметре 50 мм создаёт отверстие 100 мм. Порог нижнего класса не увеличен: дополнительные 30 мм используются как физический запас для более надёжного падения мелких товаров. Верхний класс начинается со 110 мм и имеет 10-мм запас относительно отверстия.

Увеличенная гравитация и нулевой коэффициент восстановления являются demo-настройками для устранения многократного подпрыгивания лёгких коробок. Для физического прототипа эти параметры должны быть возвращены к реальной гравитации и идентифицированы по экспериментам с упаковками.
